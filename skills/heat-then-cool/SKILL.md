# Heat Then Cool

## When to use it
Fire only when two or more different fixes, drafts or changes left a result unmoved (theirs and yours, this session). If they were variants of one design, use look-at-the-frame; never run both. Otherwise ignore everything below and answer as you would without this skill.

## What to do, in your thinking
1. Treat the current belief as one candidate.
2. Re-read the raw evidence (error text, numbers, their words) and mark what the belief made you skip.
3. Heat: write four or more explanations differing in kind, one contradicting the belief, one at a different level (data, environment, audience, process). No judging yet.
4. Cool: apply hard constraints one at a time (confirmed facts, requirements, checks run), noting which dropped each candidate; if none survive, return to step 3. Keep one resting on an unknown only if its check names and would reveal it. Drop any resting on a guess about motives.
5. For each survivor, write a separating prediction and the cheapest check. Call a check done only if you ran it and can quote its output.

## What the person sees
- Open on the observation that most changes the explanation; call it decisive only if it rules out the rest.
- If the evidence singles out one cause, give it and the fix. Otherwise two or three survivors, most likely first, each with what would confirm it; say if the original belief survives.
- Checks, cheapest first, with actions: if X, do A; if Y, do B. A requested deliverable builds on the leading explanation.
- If several survive, say what would promote the second.

Never print the worksheet, step names or percentages, or state an unknown as true. Facts about their situation (people, places, money, timing, setting) come only from them; general technical knowledge is fine, and flag a recalled figure only if they will copy it. At most two questions, each saying what it changes. No longer than a plain answer, never over 650 words. Cut any line that does not change their next step.

## Where the idea comes from
Carhart-Harris (entropic brain, 2014; REBUS with Friston, 2019): psychedelics loosen high-level beliefs so bottom-up information flows. The authors compare this to annealing: heat lets a stuck system move, cooling settles it. The same loosening makes false insight more likely.

## Limits
- The belief stays in context; step 2 guards, not guarantees.
- Explanations may be one idea reworded.
- Tested only with Opus 5.5 answering, on 8 stuck tasks and 2 ordinary ones (see evals/ in the repo).
